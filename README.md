# Urgencias365

Aplicación web progresiva educativa para medicina de urgencias.

Incluye los módulos actuales de casos, temas e investigación tipo test, más una nueva sección `Simulacion/` con el simulador educativo de gasometría en `Simulacion/Gasometria/`.

## Publicación en GitHub Pages

Sube el contenido de esta carpeta a la raíz del repositorio manteniendo las rutas y subcarpetas. Activa GitHub Pages para la rama/carpeta correspondiente. No subas solo el archivo ZIP.

El simulador es una ayuda docente: no guarda los valores introducidos y no sustituye el juicio clínico, las guías locales ni las referencias del laboratorio.
